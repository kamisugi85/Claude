## 1 accepted shotあたりの期待コスト(重視すべき指標)

```
期待コスト = 生成単価(1ショットあたり) × 想定再生成回数(regen倍率)
```

**現時点でどのProviderも実際にCLAUDE-D01のショットを生成した実績がゼロ**のため、
regen倍率は実データに基づく値ではなく、各社が公開する人物一貫性機能の有無からの
**推測**です。GPT側の実地検証(Invideo無料枠で静止画止まりだった)が示す通り、
「動く・自然に見える」水準に届くかは実際に生成してみないと分かりません。

| Provider | 生成単価(26秒あたり) | 推定regen倍率(未検証・仮定) | 期待コスト(仮定に基づく参考値) |
|---|---|---|---|
| MiniMax Hailuo | 約$1.4 | 1.5〜2.5倍(Subject-Reference機能はあるが1枚参照、複数ショット間の一貫性は未検証) | 約$2.1〜$3.5 |
| Seedance 2.5(720p運用) | 約$6.0 | 1.2〜2.0倍(最大50点のマルチモーダル参照で一貫性を作り込める可能性、ただし未検証) | 約$7.2〜$12.0 |
| Kling 3.0 | 約$3.6〜$4.4 | 1.3〜2.0倍(Character ID/Elements機能あり) | 約$4.7〜$8.8 |
| Runway Gen-4 Turbo(参照画像方式) | 約$1.3+画像生成費 | 1.2〜1.8倍(固定参照画像を使い回せるため一貫性は比較的安定しやすいと推測) | 約$1.6〜$2.4+画像生成費 |

**この表のregen倍率は仮定であり、実測ではありません。** 実際に課金を開始した際は、
まず少量(4〜8ショット程度)の実生成テストで実際のregen率を計測し、この表を
実測値で更新することを推奨します。

### 結論(暫定推奨)

- **単価・期待コストの両面でMiniMax Hailuoが最有力候補**。ただし日本からの
  アカウント利用可否・商用利用規約の細部は未確認のため、契約前にご自身での
  確認が必要です。
- **Seedance 2.5(実装済み)は、1080pでは高コストだが、720p運用に落とせば
  MiniMaxの4倍程度で許容範囲**。マルチモーダル参照による人物一貫性の強さが
  実証されれば、regenコスト削減で総コストが逆転する可能性もあります(未検証)。
- Runway Gen-4 Turbo(image-to-video)は、固定の参照画像を使い回すことで
  人物一貫性を安定させつつ最安クラスのコストを狙える組み合わせとして有望
  ですが、別途「参照画像生成」の工程が増えるため、パイプライン変更が必要です
  (今回はコード実装していません)。

**今回、MiniMax Hailuo Provider(`production/providers/minimax_hailuo.py`)を
Seedance 2.5と同じ設計パターンで実装済みです**(`MINIMAX_API_KEY`未設定のため
一切呼び出していません)。`CLAUDE-D01.json`の`provider_preferences`は
`["minimax_hailuo", "seedance", "replicate_video", "manual"]`の順に更新済みで、
キーを設定するだけでコード変更なしに試せる状態です。

## 推奨 日本語TTS

espeak-ng(現状のplaceholder、機械的な読み上げ)を置き換える候補として、
主要クラウドNeural TTSを比較しました。

| 候補 | 商用利用 | 価格目安 | 自然さ | 備考 |
|---|---|---|---|---|
| **Azure AI Speech Neural(推奨)** | ○(標準Azure利用規約) | 約$16/100万文字(Neural)、無料枠 月50万文字 | 高い(ja-JP-NanamiNeural等、放送品質に近い) | 長年安定稼働している公開API、確度高 |
| Google Cloud TTS(Neural2/Chirp3-HD) | ○ | 同水準($16/100万文字前後) | 高い | Azureとほぼ同格、どちらでも可 |
| Amazon Polly Neural | ○ | 同水準 | 高い | 同上 |
| ElevenLabs | ○(有料プラン) | 従量なら割高(数百円/1000文字相当) | 非常に高い(感情表現に強み) | コスト重視なら優先度は下げる |
| VOICEVOX(無料・ローカル) | ○(**クレジット表記必須**、無表記なら1キャラ40万円/契約) | **0円**(自己ホスト) | 中(キャラクターボイス寄り、自然な大人の会話音声としては上記Neural系に劣る) | 動画概要欄等への「VOICEVOX:キャラクター名」表記が必須 |

**推奨: Azure AI Speech Neural(`ja-JP-NanamiNeural`)。** 費用が実質無視できる
水準($16/100万文字、CLAUDE-D01の台本は約150文字 → 1本あたり1円未満)でありながら、
espeak-ngとは比較にならない自然さが期待できます。無料枠(月50万文字)だけで
当面の検証は完全に賄えます。

`production/tts/azure_provider.py`を`TTSProvider`インターフェースに沿って実装済み
(`AZURE_SPEECH_KEY`/`AZURE_SPEECH_REGION`未設定のため未呼び出し)。job JSONの
`tts.provider`を`"azure_neural"`に切り替えるだけで有効化できますが、**今回は
espeak-ngのままにしています**(キー未発行のため)。

VOICEVOXは「完全無料」を維持したい場合の代替として有効ですが、(1)クレジット
表記の運用が必要、(2)音声の性格が「キャラクターボイス」寄りで、確認された
品質基準(自然な会話感)には Azure 系ほど適合しない可能性があるため、二番手の
位置づけとしました。

## 6. 無料方式から有料方式に変えることで消える本人作業

- 無料枠サービス(Invideo/Dreamina等)への毎回のログイン・手動プロンプト投入・
  生成待機・ダウンロード・ファイル転送(`ingest-shot`への受け渡し)が不要になる
- 無料クレジット不足時に「静止画へフォールバックするか」を都度判断する作業が
  不要になる(GPT側で実際に発生した問題)
- 複数の無料サービスを使い分けて枠を使い切ったら次を試す、といった運用が不要
- 残る人的作業: 初回のアカウント作成・APIキー発行(1回限り)、生成結果の
  NGショット最終判断(regen要否の承認)、BGM/SFXのライセンス素材選定

## 7. 課金開始前にお願いしたい最小限の操作

### MiniMax Hailuo(動画・推奨候補)
1. platform.minimax.io でアカウント作成(国際版エンドポイント`api.minimax.io`を
   使うこと。中国本土向け`api.minimaxi.com`ではありません)
2. コンソールで動画生成(MiniMax-H3)がアカウント/地域で有効か、日本からの
   利用・商用利用規約を確認(未確認事項です)
3. 支払い方法を登録し、**従量課金(pay-as-you-go)のAPIキー**を選択(固定月額の
   Token Planではなく)
4. APIキー発行 → 環境変数 `MINIMAX_API_KEY` に設定
5. 設定後、`CLAUDE-D01.json`の`provider_preferences`は既に`minimax_hailuo`が
   先頭のため、`python -m production.cli render CLAUDE-D01`だけでコード変更
   なしに切り替わります

### Azure AI Speech(TTS・推奨候補)
1. Azureアカウント作成(Speech用の無料枠が月50万文字あります)
2. Azure Portalで「音声認識サービス(Speech)」リソースを作成、リージョンを
   選択(日本リージョン`japaneast`等での利用可否をご自身で確認してください)
3. リソースのキーとリージョンを控える
4. 環境変数 `AZURE_SPEECH_KEY` / `AZURE_SPEECH_REGION` に設定
5. `CLAUDE-D01.json`の`tts.provider`を`"azure_neural"`に変更(この1行の変更は
   まだ実施していません — ご指示があれば反映します)
